Clique gives Java developers a clean, expressive API for building beautiful terminal applications — no dependencies, no surprises. From inline markup tags to full-featured tables, progress bars, and custom color themes, Clique covers everything you need to make your CLI output look great.

## Why Clique?

Clique was built for Java developers who want rich terminal output without the complexity of large dependencies or low-level ANSI wrangling.

<CardGroup cols={3}>
  <Card title="Zero Dependencies" icon="feather">
    Ships with no runtime dependencies. Pure Java 21, GraalVM native image compatible.
  </Card>
  <Card title="no-color Compliant" icon="ban">
    Respects the `NO_COLOR` environment variable automatically per the spec.
  </Card>
  <Card title="24-bit Color" icon="droplet">
    Full RGB and per-character gradient rendering on truecolor terminals.
  </Card>
</CardGroup>

## Get Started

<Steps>
  <Step title="Add the dependency">
    Add `clique-core` to your Maven or Gradle project. Requires JVM 21+.
  </Step>
  <Step title="Style your first string">
    Use the markup parser or Ink API to apply colors and styles to terminal output.
  </Step>
  <Step title="Add components">
    Render tables, progress bars, trees, and more with a single `.render()` call.
  </Step>
  <Step title="Customize with themes">
    Register a built-in theme or build your own to unify your terminal's color palette.
  </Step>
</Steps>
